# Լոգարիթմներ — webpage + formula game

Թարմացված տարբերակ։ Էջը աշխատում է ամբողջությամբ offline։

## Ինչ կա ներսում

- log, lg, ln բացատրություններ
- պայմաններ՝ `a > 0`, `a ≠ 1`, `x > 0`
- հիմնական բանաձևեր
- շատ օգտագործվող փոխակերպումներ, օրինակ՝ `2lg√3 = lg(√3)^2 = lg3`
- յուրաքանչյուր փոխակերպման մոտ նշված է՝ որ հիմնական բանաձևից է գալիս
- ինտերակտիվ հաշվիչ
- բանաձևերի քարտերի խաղ
- վիճակագրություն localStorage-ով

## Բանաձևերի քանակ

Այս տարբերակում բանաձևերի/փոխակերպումների քարտերի քանակը՝ 35։
