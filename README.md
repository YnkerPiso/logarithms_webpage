# Լոգարիթմներ — log, lg, ln

Սա ամբողջական static webpage է՝ լոգարիթմները սովորելու համար։ Աշխատում է offline՝ առանց backend-ի և առանց արտաքին library-ների։

## Ինչ կա ZIP-ում

- `index.html` — գլխավոր էջը
- `css/styles.css` — ամբողջ դիզայնը
- `js/app.js` — բանաձևերի բանկ, հաշվիչ, քարտերի խաղ, վիճակագրություն

## Ֆունկցիաներ

- Log/lg/ln բացատրություն
- Պայմաններ՝ `a > 0`, `a ≠ 1`, `x > 0`
- 20 բանաձևերի ամբողջական բանկ
- Բանաձևերի filter և copy կոճակներ
- Կարճ շպարգալկա
- Ինտերակտիվ հաշվիչ՝ `log_a x`, `lg x`, `ln x`
- Քարտերի խաղ՝ randomized order + randomized side
- Պատասխանի textbox և right/wrong feedback
- Statistics page՝ localStorage-ով
- Dark/light mode

## Ինչպես բացել

Բացիր `index.html` ֆայլը browser-ով։

## GitHub Pages

Upload արա այս ZIP-ի ներսի ֆայլերը քո repository-ի մեջ։ Եթե repository-ն արդեն կոչվում է `logarithms_webpage`, պարզապես փոխարինիր հին `index.html`, `css`, `js` ֆայլերը նորերով։
