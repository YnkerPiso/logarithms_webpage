log Լոգարիթմներ log • lg • ln • cards
Իմաստը Տեսակներ Բանաձևեր Հավասարումներ Հաշվիչ Խաղ Վիճակագրություն

Մաթեմատիկայի արագ ուղեցույց

Ամեն ինչ log, lg, ln լոգարիթմների մասին

Լոգարիթմը պատասխանում է հարցին․ ինչ աստիճանի պետք է բարձրացնել հիմքը, որպեսզի ստանանք տրված թիվը։ Այս էջում կա բացատրություն, լրիվ բանաձևերի բանկ, հաշվիչ և քարտերի խաղ՝ բանաձևերը հիշելու համար։

Տեսնել 20 բանաձևերը Խաղալ քարտերով Բացել հաշվիչը

Արագ միտք

Եթե ay = x ապա logax = y
  • log28 = 3, որովհետև 23 = 8։
  • ln e = 1, որովհետև e1 = e։
  • lg 1000 = 3, որովհետև 103 = 1000։
01

Հիմունք

Ի՞նչ է լոգարիթմը

Լոգարիթմը աստիճանացույց է։ Այն ցույց է տալիս՝ հիմքը քանիերորդ աստիճան պետք է բարձրացնել։

Սահմանում

logax = y ⇔ ay = x

Այստեղ a-ն հիմքն է, x-ը լոգարիթմվող թիվը, իսկ y-ը արդյունքն է։

Պայմաններ

  • x > 0 — լոգարիթմվող թիվը պետք է դրական լինի։
  • a > 0 — հիմքը պետք է դրական լինի։
  • a ≠ 1 — հիմքը չի կարող լինել 1։

Եթե հիմքը 1 լինի, ապա 1y միշտ 1 է, այսինքն տարբեր արդյունքներ չեն ստացվում։

02

Տարբերություններ

log, lg, ln

Նշանակումը կախված է հիմքից։ Ամենաշատ օգտագործվողներն են 10-ը և e-ն։

Նշանակում Կարդացվում է Հիմք Օրինակ Նշում
logax լոգարիթմ հիմքով a a log28 = 3 ընդհանուր տեսք
lg x տասնորդական լոգարիթմ 10 lg 100 = 2 lg x = log10x
ln x բնական լոգարիթմ e ≈ 2.71828 ln e = 1 ln x = logex
log x կախված է պայմանից հաճախ 10 log 1000 = 3 դպրոցում հաճախ նույնն է, ինչ lg
Քննության մեջ ուշադիր եղիր․ եթե գրված է lg, հիմքը հաստատ 10 է։ Եթե գրված է ln, հիմքը հաստատ e է։
03

Բանաձևերի բանկ

20 կարևոր բանաձև

Սրանք նույն բանաձևերն են, որոնք օգտագործվում են քարտերի խաղում։ Ամեն քարտի մի կողմը ձախ մասն է, մյուս կողմը՝ աջ մասը։

Ընդհանուր պայմաններ․ a > 0, a ≠ 1, b > 0, b ≠ 1, x > 0, y > 0
04

Օրինակներ

Քայլ առ քայլ

Լոգարիթմը լուծելիս ամենահեշտը այն աստիճանի տեսքի բերելն է։

Օրինակ 1

log381

  1. Հարցնում ենք՝ 3-ը քանիերորդ աստիճան է 81։
  2. 34 = 81
  3. Ուրեմն log381 = 4
Օրինակ 2

lg 0.01

  1. lg նշանակում է հիմք 10։
  2. 0.01 = 10−2
  3. Ուրեմն lg 0.01 = −2
Օրինակ 3

ln e5

  1. ln-ի հիմքը e է։
  2. ln(e5) = 5 · ln e
  3. ln e = 1, ուրեմն պատասխանը 5
05

Հավասարումներ

Լոգարիթմային հավասարումներ

Լուծելիս առաջին քայլը միշտ որոշման տիրույթն է՝ լոգարիթմի ներսը պետք է դրական լինի։

Տեսակ 1

logaf(x) = c ⇒ f(x) = ac

Պայման՝ f(x) > 0

Տեսակ 2

logaf(x) = logag(x) ⇒ f(x) = g(x)

Պայման՝ f(x) > 0 և g(x) > 0

Լուծված օրինակ

log2(x − 1) = 3

Պայման՝ x − 1 > 0 ⇒ x > 1

x − 1 = 23 = 8 ⇒ x = 9

06

Գրաֆիկ

y = logax հատկությունները

Լոգարիթմային ֆունկցիան ունի ուղղահայաց ասիմպտոտ x = 0 և անցնում է (1, 0) կետով։

Եթե a > 1

Ֆունկցիան աճում է։ Օրինակ՝ log2x։

Եթե 0 < a < 1

Ֆունկցիան նվազում է։ Օրինակ՝ log1/2x։

07

Ինտերակտիվ հաշվիչ

Հաշվիր logax, lg x և ln x

Արժեքները մոտավոր են։ Հաշվիչը նաև ցույց է տալիս՝ պայմանները ճիշտ են, թե ոչ։

logax2
lg x2
ln x4.60517
Պայմանները ճիշտ են։
Հուշում հաշվիչի համար logax = ln x / ln a = lg x / lg a
08

Սխալներ

Ամենատարածված սխալները

Այս սխալներն են ամենաշատը հանդիպում թեստերում։

✗

loga(x + y) = logax + logay

Սա սխալ է։ Գումարի լոգարիթմի համար նման կանոն չկա։

✗

Մոռանալ x > 0 պայմանը

Օրինակ՝ log(x − 3)-ի համար պետք է x − 3 > 0 ⇒ x > 3։

✗

lg և ln խառնելը

lg-ի հիմքը 10 է, ln-ի հիմքը e է։ Սրանք նույնը չեն։

✗

Հիմքը 1 վերցնելը

log1x գոյություն չունի, որովհետև հիմքը չի կարող լինել 1։
