log Լոգարիթմներ log • lg • ln • e
Իմաստը Տեսակներ Բանաձևեր Հավասարումներ Հաշվիչ
Մաթեմատիկայի արագ ուղեցույց

Ամեն ինչ log, lg, ln լոգարիթմների մասին

Լոգարիթմը պատասխանում է հարցին․ ինչ աստիճանի պետք է բարձրացնել հիմքը, որպեսզի ստանանք տրված թիվը։ Այս էջը հավաքում է սահմանումները, կանոնները, փոխարկումները, օրինակները և ինտերակտիվ հաշվիչը մեկ տեղում։

Տեսնել բանաձևերը Բացել հաշվիչը
Եթե ay = x ապա logax = y

Արագ միտք

log28 = 3, որովհետև 23 = 8։

ln e = 1, որովհետև e1 = e։

lg 1000 = 3, որովհետև 103 = 1000։

🔎
01

Ի՞նչ է լոգարիթմը

Լոգարիթմը աստիճանացույց է։ Այն ցույց է տալիս՝ հիմքը քանիերորդ աստիճան պետք է բարձրացնել։

Սահմանում

logax = y ⇔ ay = x

Այստեղ a-ն հիմքն է, x-ը լոգարիթմվող թիվը, իսկ y-ը արդյունքն է։

Պայմաններ

  • x > 0 — լոգարիթմվող թիվը պետք է դրական լինի։
  • a > 0 — հիմքը պետք է դրական լինի։
  • a ≠ 1 — հիմքը չի կարող լինել 1։

Ինչու՞ a ≠ 1

Որովհետև 1y = 1 ցանկացած y-ի համար, այսինքն տարբեր արդյունքներ չեն ստացվում։

02

log, lg, ln տարբերությունները

Նշանակումը կախված է հիմքից։ Ամենաշատ օգտագործվողներն են 10-ը և e-ն։

Նշանակում Կարդացվում է Հիմք Օրինակ Նշում
logax լոգարիթմ հիմքով a a log28 = 3 ընդհանուր տեսք
lg x տասնորդական լոգարիթմ 10 lg 100 = 2 lg x = log10x
ln x բնական լոգարիթմ e ≈ 2.71828 ln e = 1 ln x = logex
log x կախված է դասագրքից/հաշվիչից հաճախ 10 log 1000 = 3 դպրոցում հաճախ նույնն է, ինչ lg
Քննության մեջ ուշադիր եղիր. Եթե գրված է lg, հիմքը հաստատ 10 է։ Եթե գրված է ln, հիմքը հաստատ e է։ Եթե գրված է log առանց հիմքի, պետք է հասկանալ ըստ տվյալ դասագրքի/պայմանի։
03

Հիմնական բանաձևեր

Այս կանոնները պետք է իմանալ լոգարիթմային արտահայտություններ պարզեցնելու և հավասարումներ լուծելու համար։

Արտադրյալ

loga(xy) = logax + logay

Բազմապատկումը դառնում է գումարում։

Քանորդ

loga(x/y) = logax − logay

Բաժանումը դառնում է հանում։

Աստիճան

loga(xn) = n logax

Աստիճանը դուրս է գալիս որպես գործակից։

Հիմքի լոգարիթմ

logaa = 1

Որովհետև a1 = a։

Մեկի լոգարիթմ

loga1 = 0

Որովհետև a0 = 1։

Հակադարձ կապ

alogax = x

Լոգարիթմը և աստիճանը հակադարձ գործողություններ են։

Փոխադարձ հիմքեր

logab = 1 / logba

Օգտակար է հիմքը շրջելիս։

Հիմքի փոխում

logax = logbx / logba

Հաշվիչի վրա կարելի է օգտագործել lg կամ ln։
04

Օրինակներ քայլ առ քայլ

Լոգարիթմը լուծելիս ամենահեշտը այն աստիճանի տեսքի բերելն է։

Օրինակ 1

log381

  1. Հարցնում ենք՝ 3-ը քանիերորդ աստիճան է 81։
  2. 34 = 81
  3. Ուրեմն log381 = 4
Օրինակ 2

lg 0.01

  1. lg նշանակում է հիմք 10։
  2. 0.01 = 10−2
  3. Ուրեմն lg 0.01 = −2
Օրինակ 3

ln e5

  1. ln-ի հիմքը e է։
  2. ln(e5) = 5 · ln e
  3. ln e = 1, ուրեմն պատասխանը 5
05

Լոգարիթմային հավասարումներ

Լուծելիս առաջին քայլը միշտ որոշման տիրույթն է՝ լոգարիթմի ներսը պետք է դրական լինի։

Տեսակ 1

logaf(x) = c

⇓

f(x) = ac

Պայման՝ f(x) > 0

Տեսակ 2

logaf(x) = logag(x)

⇓

f(x) = g(x)

Պայման՝ f(x)>0 և g(x)>0

Տեսակ 3

ln f(x) = ln g(x)

⇓

f(x) = g(x)

Նույն հիմք e, նույն կանոնը։

Լուծված օրինակ

log2(x − 1) = 3

Պայման՝ x − 1 > 0 ⇒ x > 1

Աստիճանի տեսքով՝ x − 1 = 23 = 8

x = 9, և 9 > 1, ուրեմն պատասխանը՝ x = 9

06

Գրաֆիկ և հատկություններ

Լոգարիթմային ֆունկցիան ունի ուղղահայաց ասիմպտոտ x = 0 և անցնում է (1, 0) կետով։

y = logax

  • Որոշման տիրույթ՝ x > 0
  • Արժեքների բազմություն՝ բոլոր իրական թվերը
  • Եթե a > 1, ֆունկցիան աճում է։
  • Եթե 0 < a < 1, ֆունկցիան նվազում է։
07

Ինտերակտիվ հաշվիչ

Հաշվիր logax, lg x և ln x արժեքները։ Արժեքները մոտավոր են։

logax 2
lg x 2
ln x 4.60517

Պայմանները ճիշտ են։

08

Ամենատարածված սխալները

Այս սխալներն են ամենաշատը հանդիպում թեստերում։

✗

loga(x + y) = logax + logay

Սա սխալ է։ Գումարի լոգարիթմի համար նման կանոն չկա։

✗

Մոռանալ x > 0 պայմանը

Օրինակ՝ log(x − 3)-ի համար պետք է x − 3 > 0 ⇒ x > 3։

✗

lg և ln խառնելը

lg-ի հիմքը 10 է, ln-ի հիմքը e է։ Սրանք նույնը չեն։

✗

Հիմքը 1 վերցնելը

log1x գոյություն չունի, որովհետև հիմքը չի կարող լինել 1։

09

Կարճ շպարգալկա

Ամենակարևորները մեկ աղյուսակում։

logax = y⇔ ay = x
lg x= log10x
ln x= logex
loga1= 0
logaa= 1
logaxy= logax + logay
logax/y= logax − logay
logaxn= nlogax

Ստատիկ էջ է՝ աշխատում է առանց ինտերնետի։ Կարող ես դնել քո quiz app-ի մեջ որպես առանձին թեմայի էջ։
